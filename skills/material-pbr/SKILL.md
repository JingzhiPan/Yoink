# 看材质：先通道，后图层

图层（高光带、压暗、白纱）是结果，通道是原因。先说清通道，图层就能推出来，不用一条一条描。

## 0. 可信区域（先做，再看别的）
在放大图上圈出**不可信**的区域，之后这些区域只能当推断，不能当证据：
- 过曝：高光核心白到没有细节的地方——看不出粗糙度，只知道"这里有镜面反射"
- 环境映射：反射里出现了窗户、灯管、拍摄者、屏幕内容——那是环境，不是材质
- 阴影里：暗到看不出底色和纹理
- 录屏/压缩糊掉：块状伪影、缩放模糊、光标压着的地方
- 相邻元素叠出来的：奶白光柱、重叠区变色，属于布局不属于单个材质

## 1. 通道摘要（一段话，图层表之前）
- **albedo**：底色和它的变化（渐变？纹理？透明度多少）
- **roughness**：高光的锐度。核心小而亮 = 低粗糙度（玻璃、湿乳胶、抛光金属）；高光宽而糊 = 高粗糙度（纸、磨砂、织物）。粗糙度均匀还是有花纹（指纹、划痕、木纹）
- **metalness**：金属的高光带底色、没有漫反射；非金属的高光是白的、底色靠漫反射。UI 里几乎都是 0
- **normal**：表面是平的、有细颗粒、有纹理走向、有大的鼓起/凹陷。决定高光和阴影的形状会不会"跟着表面走"
- **AO**：接缝、卷边、内角、两个元素贴合处的暗。只在几何凹处，不在平面上
- **透光**（薄材质加一条）：次表面散射带来的暖色透光、薄处淡厚处浓

每一层图层都要能挂到一个通道上；挂不上的，要么是环境（不画），要么是多元素叠加（标明）。

## 2. 常见材质速查
| 材质 | roughness | normal | 透光 | 边缘 | 露馅点 |
|---|---|---|---|---|---|
| 玻璃 / 亚克力 | 低，均匀 | 平 | 有，折射 | 菲涅尔反光，薄亮线 | 四边压暗过重就变宝石 |
| 磨砂玻璃 | 中，均匀 | 微颗粒 | 有，散射 | 柔和 | 背后模糊不够就像塑料 |
| 乳胶 / 硅胶 | 低到中，均匀 | 平，拉伸处更平 | 强，暖色 | 菲涅尔压暗明显 | 高光太宽像磨砂，太锐像塑料壳 |
| 塑料薄片 | 低 | 平，中间略鼓 | 弱 | 四边压平 | 缺中心鼓起就像贴纸 |
| 金属 | 低到中，有划痕 | 拉丝 / 平 | 无 | 硬反光 | 高光不带底色就像塑料 |
| 纸 / 卡纸 | 高 | 细颗粒 | 弱 | 无反光，只有 AO | 加了高光就像塑封 |
| 果冻 / 凝胶 | 低 | 平，大鼓起 | 强 | 亮边 | 没有透光就是彩色玻璃 |
| 木头 | 中到高，沿纹理变 | 木纹走向 | 无 | 无 | 粗糙度不沿纹理变就像贴图 |
| 织物 | 高 | 编织纹 | 无 | 绒毛边 | 有镜面高光就错 |

## 3. 画材质：按写实度决定挂几层
写实度是设计决定，分析结果永远精确，渲染按预算：
- **平面**：只画 albedo，一层描边。不要高光、不要阴影
- **风格化**：albedo + 一道高光 + 一条边缘线。高光形状可以概括，不必物理准确
- **拟物**：+ AO + 由 roughness 决定形状的高光 + 菲涅尔边缘 + 透光。所有高光阴影从光源约定推
- **写实**：+ normal 噪声或纹理 + 微观颗粒 + 多层菲涅尔 + roughness 沿纹理变化

超出档位的层一律不画，哪怕照片里有。

## 4. normal 不是平的时候：程序化纹理，不贴图
SVG filter 一组三件套，叠成一层 `mix-blend-mode: soft-light` 或 `overlay` 压在 albedo 上：
```html
<filter id="grain">
  <feTurbulence type="fractalNoise" baseFrequency="0.9" numOctaves="3" seed="2" result="n"/>
  <feComponentTransfer in="n" result="h"><feFuncA type="table" tableValues="0 0.35"/></feComponentTransfer>
  <feDiffuseLighting in="h" surfaceScale="1.2" lighting-color="#fff"><feDistantLight azimuth="<光源方位角>" elevation="55"/></feDiffuseLighting>
</filter>
```
- baseFrequency 大 = 颗粒细；numOctaves 多 = 层次多；木纹用 `baseFrequency="0.02 0.4"` 这种横竖不等
- azimuth 必须等于光源约定的方向，否则纹理的光和高光的光打架
- 只在 normal 通道不平的材质上用；平面和风格化档位禁用
- 静态一次渲染即可，禁止每帧改 seed

## 5. 自查时的多状态原则
材质要在每个状态下都读得通：光源没动、形状动了，高光和 AO 要跟着表面走；hover 提亮不是整体加白，是高光核心变亮；按压变形时菲涅尔边缘跟着轮廓走。只有初始态对、其他状态不对，说明层是画上去的不是推出来的。
